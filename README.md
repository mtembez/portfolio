# Simon Munyambu — Systems & AI/ML Engineer Portfolio

> **Live Production Website:** [https://mtembez.github.io/portfolio/](https://mtembez.github.io/portfolio/)

High-craft, zero-bloat personal portfolio and systems telemetry console for **Simon Munyambu**, Software & AI/ML Systems Engineer based in Nairobi, Kenya.

---

## ⚡ Architectural Highlights

- **Embedded Systems Terminal:** Interactive in-browser POSIX shell emulator with command parser (`help`, `skills`, `projects`, `bio`, `bench`, `neofetch`, `contact`).
- **Celestial Lion Constellation:** Canvas 2D particle simulation rendering a low-poly lion constellation with interactive mouse gravity.
- **Holographic 3D Portrait Card:** Magic UI rotating border-beam, Emil Kowalski 3D perspective mouse tilt, and subpixel drop-shadow depth grading.
- **Aceternity Spotlight Tracking:** Cursor-tracking radial gradient overlays across all Bento grid and project cards.
- **Web Audio SFX Engine:** Real-time synthesized acoustic feedback on keystrokes and navigation using native Web Audio API oscillators.
- **Live Nairobi Systems Telemetry:** Real-time East Africa Time (UTC+3) clock and edge latency telemetry.
- **Paco Coursey `cmdk`:** Universal command palette modal triggered via `⌘K` / `Ctrl+K`.
